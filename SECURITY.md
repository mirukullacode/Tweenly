# Security policy

## Reporting a vulnerability

Please don't open a public issue. Email **imanjunad@gmail.com** with:

- what you found and where (component, page or API route),
- steps to reproduce,
- the impact you expect.

You'll get a reply within 3 days. Once it's fixed, you'll be credited in the changelog unless you'd rather not be.

## Scope

- The documentation site and its API routes (`/api/*`).
- Component source in `registry/`, which users copy into their projects.
